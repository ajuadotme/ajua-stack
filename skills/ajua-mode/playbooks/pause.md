# 安全暫停

把進行中的工作停在可接續的狀態，留下一份接續紀錄，讓沒有這段對話記憶的代理也能照 `pickup.md` 接手。只在使用者明確要求暫停時適用。聽到「繼續」「我去睡了，你繼續」「不要停」時，不暫停。

1. **停在安全的邊界。** 做完目前這個不可分割的步驟，或退回它之前。不開始新工作。
2. **收掉子代理。** 不再派新的子代理，停掉所有進行中的子代理。在 worktree 裡有改動的，把改動 commit 到它的 branch。每個子代理的交辦、停在哪、worktree 路徑與 branch，寫進接續紀錄。
3. **不為了暫停做不可復原的動作。**
4. **把改動存成 commit。** 你的未 commit 改動，在目前的 branch 做成一個 `wip:` commit，確保什麼都不會遺失。程式目前是壞的，在 commit 內文用一行寫明哪裡壞。不是你做的改動不動，在接續紀錄裡列出。
5. **寫接續紀錄。** 寫到專案的 `.claude/resume.md`，不只留在對話裡。這個檔案不進版本紀錄（加進 gitignore），判斷工作樹是否乾淨時忽略它。內容：目標、進行到流程表的哪一步、已驗證的部分與證據、目前狀態（branch、寫紀錄當下的最後一個 commit、工作樹是否乾淨、各 worktree 與停掉的子代理）、下一步、關鍵檔案、要注意的陷阱。已經有 `worklog` 技能留下的紀錄，指向它，不重抄。

**回報：** 停在流程的哪一步、哪些已存到磁碟（給路徑，不貼 diff）、做了哪些 commit、工作樹是否乾淨、接續紀錄的路徑、接手時的第一個動作。這是暫停，不是最終回報。
