# 撰寫技能

新增或修改一個 SKILL.md。只留會改變決定的文字。

1. **撰寫。** 寫法照 `writing` 技能：讀 `${CLAUDE_PLUGIN_ROOT}/skills/writing/SKILL.md` 並照做。拿不準就刪。叫它做事，省略理由；只有沒附理由會讓人困惑時才解釋。語氣配合範圍。指向結構性的來源（型別、README、設定），不重述。要用其他技能時，用路徑交給它，不重述它的內容。
2. **驗證。** frontmatter 有 `name` 與 `description`，引用的檔案都存在，跨技能的連結都能解析。實際檢查，不憑印象。
3. **寫測試案例。** 技能屬於結構性的，寫測試案例。屬於主觀判斷的，略過。
4. **存檔。** 依入口檔的「存檔」一節。目的地不在 git 內時略過這一步。
5. **提議新技能。** 一再碰到卻沒被收錄的工作流程，向使用者提議做成新技能。

**回報：** 技能摘要、關鍵的設計決定、驗證紀錄。
