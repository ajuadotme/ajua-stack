# How

回答「X 怎麼運作」。不改任何檔案。

1. 範圍不明確時，先說明你的解讀，再開始。使用者可以改方向。
2. 派一個 `subagent_type: "Explore"` 的子代理追蹤相關程式。交辦寫明：不改檔案；產出概觀、關鍵概念、運作流程、檔案位置、容易踩的坑；每個說法附檔名與行號。
3. 抽查子代理引用的關鍵位置，確認屬實。
4. 呈現結果。先用白話講它做什麼，再講怎麼做到。沒有出處的說法，標明是推論。
