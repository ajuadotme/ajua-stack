# Sharpen

要的是任務的更深入版本，不是更大的版本。只改寫提示詞並交還，不動手做任務。

改寫前，先做四件事：

1. 說出這個領域的頂尖專業人士在這裡會做、而提示詞沒有要求的事。
2. 說出他們會從哪種最原始的素材開始，而不是拿到已經消化過的東西。
3. 說出他們會用的具體方法與工具。
4. 說出除了你與使用者之外，還有什麼能證明結果是對的。

然後重寫提示詞，要求的正是這些。

重寫後的提示詞要求代理：任何能用實驗解決的選擇，先做原型，再依觀察到的結果推薦一個選項。沒有任何實驗能解決的產品或偏好選擇，留給使用者決定。
