# ajua-stack 導覽

ajua-stack 讓 Claude 照固定流程工作，並拿出實際證據證明成果。這份導覽依使用順序分章，第一次使用請從頭讀。

1. [安裝與第一個任務](./01-start.md)：安裝、跑第一個任務、讓 Claude 能自行驗證。
2. [怎麼下指令](./02-prompting.md)：目標、完成條件、證據、限制，以及怎麼用一句話修正方向。
3. [動手前先搞懂](./03-understand.md)：用 `how`、`why`、`teach`、`recall`、`blast-radius` 看懂現況。
4. [做東西](./04-build.md)：試做比較、加功能、修問題、整理、效能調校、畫面比對，以及完成後的檢查。
5. [大型與長時間的工作](./05-long-work.md)：多階段計畫、暫停與接手、自主執行、多代理、清理 worktree。
6. [讓外掛越用越合你](./06-make-it-yours.md)：整理教訓、把重複的錯誤變成檢查、寫自己的技能、設定模型。
7. [常見錯誤](./07-pitfalls.md)：容易踩的錯，以及該怎麼做。

## 先記住三件事

- 指令都要加前綴，例如 `/ajua-stack:ajua-mode`、`/ajua-stack:how`。
- 流程表不是指令。描述任務，`ajua-mode` 會自己選。
- 小改動直接說就好，不需要 `ajua-mode`。
